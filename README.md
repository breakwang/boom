# 抽奖游戏

一个现代化的抽奖游戏系统，支持自定义奖池和可调节的点数分配差距。

## 功能特点

- 🎯 **灵活的奖池设置**: 输入参与人数和人均点数创建奖池
- 🎲 **随机点数分配**: 将奖池总点数随机分配到10个编号
- 📊 **可调节差距**: 通过滑块调整点数分配的差距（0-100%）
  - 0%: 所有编号点数相近，接近均分
  - 100%: 点数差距极端，可能出现非常高或非常低的奖项
- 🔥 **极限模式**: 可能出现0点或超高倍数（3-5倍）的刺激玩法
- 💾 **本地状态同步**: 游戏状态自动保存，多个标签页/窗口实时同步
- 👥 **多人共享**: 同一设备多个窗口打开，所有人看到同一个游戏状态
- 🎨 **美观的UI设计**: 现代化的渐变色彩和流畅的动画效果
- 📱 **响应式设计**: 完美支持桌面和移动设备
- 🎉 **震撼动画**: 翻牌抖动、屏幕闪光、彩纸爆炸等特效
- ⚡ **连击系统**: 快速连续抽奖触发连击特效
- 📝 **抽奖记录**: 实时显示抽奖历史

## 使用方法

1. **创建奖池**
   - 输入参与人数（如 10 人）
   - 输入人均点数（必须是10的倍数，如 100 点）
   - 调整点数差距滑块（0-100%）
   - 点击"创建奖池"按钮

2. **开始抽奖**
   - 点击任意未揭晓的编号进行抽奖
   - 查看获得的点数
   - 重复直到用完所有抽奖次数

3. **其他功能**
   - 点击"揭晓所有"按钮查看所有未抽取的奖项
   - 点击"重新开始"按钮重新设置奖池
   - 状态自动保存，刷新页面或新开窗口都能看到当前进度

**小提示**：
- 差距设为 **0%** = 所有编号点数接近均分
- 差距设为 **50%** = 适中差距，有惊喜
- 差距设为 **100%** = 极端差异，刺激！
- 勾选 **🔥 极限模式** = 可能出现0点或超高倍数

## 多人使用说明

### 同步机制
- **自动保存**: 每次创建奖池或抽奖后，状态自动保存到浏览器本地存储
- **实时同步**: 在同一台设备上打开多个窗口/标签页，所有窗口实时同步
- **状态恢复**: 刷新页面后自动恢复到上次的游戏状态
- **跨窗口通信**: 使用 localStorage + storage 事件实现跨标签页同步

### 使用场景
1. **多人轮流抽奖**: 每个人打开一个窗口，看到的都是同一个奖池
2. **投屏展示**: 一个窗口用于投屏展示，另一个窗口用于操作
3. **断点续玩**: 意外关闭后重新打开，游戏进度不会丢失

### 重置游戏
- 点击"重新开始"按钮会清除所有保存的状态
- 清除浏览器数据也会重置游戏

### 状态指示
- 页面右下角显示"多人同步"状态指示器
- 绿色脉冲点表示同步功能正常运行

## 技术实现

- **纯前端实现**: HTML + CSS + JavaScript
- **无需服务器**: 可直接在浏览器中运行
- **本地存储**: 使用 localStorage 持久化游戏状态
- **跨窗口同步**: 监听 storage 事件实现实时同步
- **响应式布局**: 使用 CSS Grid 和 Flexbox
- **动画效果**: CSS3 动画和 JavaScript 动态效果

## 算法说明

点数分配算法根据差距系数生成不同的权重：
- 所有点数都是10的倍数
- 保证总点数精确等于输入的奖池总点数
- 差距系数越大，点数分布越不均匀
- 使用随机数和权重函数确保每次分配都不同
